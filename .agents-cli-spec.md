# Agent Spec

## Overview
Smart Study Planner is a local Google ADK prototype that turns a student's exam requirements into a personalized day-wise study plan. It uses sequential, parallel, and loop agents to extract requirements, analyze topics and practice needs, draft a schedule, review it, and present the result.

## Example Use Cases
- Given a subject, preparation days, current level, syllabus topics, and available hours per day, produce a complete study plan covering exactly those days.
- If any required detail is missing, ask only for the missing information instead of inventing it or generating a partial plan.
- If a draft exceeds the daily time allowance or omits a topic, return specific corrections and revise the plan.

## Tools Required
- Existing Gemini model configuration only.
- Local deterministic study-plan validation; no external API, database, or authentication is added.

## Constraints & Safety Rules
- Preserve the existing model name and environment configuration.
- Never invent missing subject, preparation days, current level, syllabus topics, or daily study hours.
- Cover every supplied topic.
- Never exceed the supplied daily study-hour limit.
- Use the requested number of preparation days; do not assume ten days.
- Include revision and a final mock test.
- Stop with an explicit validation failure if the iteration limit is reached without approval.

## Success Criteria
- The workflow imports successfully and preserves its existing model configuration.
- Missing-input requests do not proceed as if a complete plan can be generated.
- No instruction contains a hard-coded ten-day requirement.
- Deterministic validation reports missing topics, incorrect day count, daily time-limit violations, and missing revision or mock-test coverage.
- Review feedback is separate from the final user-facing presentation.
